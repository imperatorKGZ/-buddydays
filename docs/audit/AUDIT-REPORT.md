## 4. Шкала серьёзности

P0 блокирует запуск либо нарушает жёсткое правило; P1 — значимый дефект функции, SEO, a11y или безопасности; P2 — заметное улучшение качества; P3 — косметика или рекомендация.

## 5. Что подтверждено и что не удалось проверить

Подтверждено: все текущие записи в `src/data/blog/articles.ts` имеют `status: "draft"`; production listing, detail route, SSG и sitemap проверяют published-статус; RSS фильтрует published; аналитический endpoint возвращает `501` и ничего не сохраняет; повторный `npm audit --omit=dev` после добавления зависимостей вывел `found 0 vulnerabilities`; `npm run build` создал 35 маршрутов.

Не подтверждено: отсутствие секретов в полной истории Git (`npx gitleaks detect --no-banner` не смог определить executable), Lighthouse (`npx lighthouse --version` начал установку, но не завершился в лимите среды), Rich Results Test, полный E2E для всех Playwright projects и нулевые axe-нарушения. Эталонный HTML главной в репозитории не найден.

## 6. Решения и вопросы владельцу

Принято: TypeScript-реестр остаётся единственным источником метаданных Phase 1; пустые MDX-каталоги не используются до отдельной миграции без изменения slug или текста. Продуктовые разделы остаются неиндексируемыми до реального проверенного наполнения. Черновики не изменяются и не переводятся в published.

Нужны решения владельца: подтвердить production-домен и `SITE_URL`; заменить placeholder icon/OG artwork лицензированными mascot-ресурсами; предоставить эталонный HTML главной; подтвердить юридические тексты и рабочий контактный канал; разрешить удаление неотслеживаемых patch-артефактов. PR не создавался.
