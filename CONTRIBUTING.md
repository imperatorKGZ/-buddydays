# Contributing

Use Node.js 20.19+ and the npm version bundled with it. Start with `npm ci`,
then run `npm run check` before proposing a change. For browser changes, also
run `npm run test:e2e`.

Do not rewrite article text, alter a draft's status, or add product/affiliate
content to the editorial library without explicit approval. Keep routes thin,
reuse shared types, and add a focused test for changed behavior.
